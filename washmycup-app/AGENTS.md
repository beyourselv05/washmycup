# Expo HAS CHANGED

This project is on **Expo SDK 54** (React Native 0.81, React 19.1).

SDK 54 is pinned on purpose: the App Store / Play Store build of Expo Go is stuck at
SDK 54, so this is the newest SDK that can be opened by scanning the dev-server QR code
on a stock phone. Do not upgrade the SDK without a plan for how the team will run the app.

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.
